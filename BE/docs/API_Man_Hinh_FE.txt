================================================================================
API THEO MAN HINH FE — Duong dan · Phuong thuc · Input · Output · JSON
================================================================================
Quy uoc:
- Base: /api/v1
- Response boc ApiResponse: { success, message, data, errors, traceId, timestampUtc }
- Tam thoi KHONG phan trang (data.items = full list)
- Auth dang TAT (TAM-TAT-LOGIN) — goi API khong can token
- Domain DB: station -> plc -> device -> tag -> history.history_1s (join bang Id)
- Format moi muc:
    Controller / File / Method / Path / DB JOIN / INPUT / OUTPUT / JSON / STATUS / MESSAGE / Summary

1. LOGIN
================================================================================
Controller : AuthController
File       : Controllers/AuthController.cs
Method     : POST
Path       : /api/v1/auth/login

INPUT (body):
  username : string
  password : string

OUTPUT (data):
  accessToken, refreshToken, expiresIn, user { id, username, displayName, role }

JSON request:
{
  "username": "admin",
  "password": "Admin@123"
}

JSON response (data):
{
  "accessToken": "...",
  "refreshToken": "...",
  "expiresIn": 3600,
  "user": {
    "id": 1,
    "username": "admin",
    "displayName": "Administrator",
    "role": "Admin"
  }
}

Summary: Dang nhap, tra token va thong tin user.

3d. THIET BI THEO TRAM (JOIN DB THEO ID)
================================================================================
Controller : StationsController
File       : Controllers/Scada/StationsController.cs
Method     : GET
Path       : /api/v1/stations/{stationId}/device-cards

DB JOIN (bat buoc theo Id — khong flatten UI):
  scada.station.id  = @stationId
       |
       v  plc.station_id = station.id
  scada.plc
       |
       v  device.plc_id = plc.id
  scada.device
       |
       v  tag.device_id = device.id  (va tag.plc_id = plc.id)
  scada.tag
       |
       v  history_1s.tag_id = tag.id  (gia tri moi nhat)
  history.history_1s

INPUT (path + query):
  stationId  : long     (scada.station.id)
  deviceId   : long?    (scada.device.id)
  deviceType : string?  (scada.device.device_type, vd: "Pump")
  isEnable   : bool?    (scada.device.is_enable)

OUTPUT (data) — chi tiet tung bang:
  station                    <- scada.station
    id, code, name, address, latitude, longitude, isActive
  items[]
    plc                      <- scada.plc (qua device.plc_id)
      id, stationId, stationCode, code, name, plcType,
      ipAddress, rack, slot, port, pollingInterval,
      reconnectInterval, timeout, maxConnection, isEnable, description, ...
    device                   <- scada.device
      id, plcId, plcCode, code, name, displayName,
      deviceType, description, isEnable, ...
    tags[]                   <- scada.tag + history.history_1s
      id, plcId, deviceId, code, tagName, displayName, address,
      dataType, unit, scale, offsetValue, readOnly, writeEnable,
      enableRealtime, enableAlarm, description,
      value, timestamp

BANG + KHOA NGOAI:
  scada.station          PK id
  scada.plc              PK id, FK station_id -> station.id
  scada.device           PK id, FK plc_id -> plc.id
  scada.tag              PK id, FK device_id -> device.id, FK plc_id -> plc.id
  history.history_1s     (time, tag_id, value) — join logic tag_id = tag.id

GHI CHU

GHI CHU STATUS / MESSAGE (constant + enum):
  HTTP     : ScadaHttpStatuses.Ok=200, NotFound=404, BadRequest=400

  Error    : ScadaErrorCodes.StationNotFound = "Station.NotFound"
  Van hanh : enum PumpOperatingStatus (Running=1, Error=2, Stopped=3, Maintenance=4, Unknown=0)
  Khoa     : enum LockStatus (Open=0, Closed=1)
  JSON FE  : ScadaStatusCodes.running|stopped|error|maintenance|unknown|open|closed
  File     : Shared/Constants/Scada*.cs , Domain/Enums/PumpOperatingStatus.cs, LockStatus.cs
